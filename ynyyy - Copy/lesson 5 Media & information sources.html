Lesson :Media Inormation Literacy

Languages, Media & Media Languages

Learning Objectives

At the end of this lesson, learners are expected to:

  • Identify the different media languages.
  • Differentiate the types of media codes, audiences, and stakeholders.
  • Explain how media codes and conventions convey meaning to an audience.

1. The Evolution of the World Wide Web

The World Wide Web has transformed from static text-based pages into fully interactive, intelligent platforms:

  • Language and Media
  • Language – Technical and symbolic ingredients, codes, and conventions used by media professionals to communicate ideas, information, and knowledge.
  • Media Codes, Conventions, and Messages
  • Types of Media Codes

2. Online Safety, Security, and Netiquette

Netiquette refers to network etiquette—the acceptable code of behavior when using the internet.

Core Rules of Netiquette for SHS Students:

  1. Remember the Human: Treat others online with the same respect you expect in person.
  2. Protect Personal Information: Avoid sharing passwords, home addresses, and phone numbers.
  3. Verify Before Sharing: Check sources to prevent spreading fake news or misinformation.
  4. Respect Intellectual Property: Always cite sources and avoid digital plagiarism.
